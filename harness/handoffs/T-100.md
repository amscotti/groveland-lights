## Exact UI contract strings encoded (for workers)

- `<section id="probe">` on `/`, populated by HTMX from `GET /probe` after
  load; server-rendered (with a plain form) when JS is disabled.
- Heading with accessible name exactly `Probe`; text `Count: N` (N ≥ 0) with
  the digits in `#probe-count`; button with accessible name exactly
  `Increment counter`.
- `GET /probe` → 200 fragment containing `Count:` and
  `<input ... name="csrf_token" ... value="...">` (attribute order free).
- `POST /probe`: missing or tampered `csrf_token` → 403, counter unchanged;
  valid + `HX-Request: true` → 200 with `Count: N+1`; valid without
  `HX-Request` → 303 with `Location: /` (increments, then redirects).
- Counter is global (not per-session) and survives SIGTERM + respawn on the
  same `DB_PATH` (SQLite).
- First migration file `migrations/0001_init.sql`; checksum stored in
  `schema_migrations` as 64-char lowercase hex; tampered checksum at startup →
  non-zero exit naming `0001_init.sql` and the word `checksum`.
