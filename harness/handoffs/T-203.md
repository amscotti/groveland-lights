## Frozen API (T-205 compiles against this)

```go
// internal/web/session.go
const SessionCookieName = "gl_session"            // frozen cookie name (A-201)
func AdminOnly(next http.HandlerFunc) http.HandlerFunc
```

- `AdminOnly` wraps a handler: valid unexpired **admin-role** session → `next`;
  otherwise full page → `302 Location: /admin/login`; any `HX-Request` header
  → `401` + `HX-Redirect: /admin/login` + **empty body**. Wrap EVERY
  `/admin*` route with it (including `GET /admin`, `/admin/walk`,
  `/admin/lights/{id}`, `/admin/rows`, the POST routes).
- Cookie value format (pinned by `TestSessionValueRoundTrip`):
  `base64url(sessionID) + "." + hex(HMAC-SHA256(SessionKey, sessionID))`.
  `SessionCookieName` cookie: `Path=/; Max-Age=86400; HttpOnly; SameSite=Lax`,
  `Secure` exactly in prod.
- Login routes already registered in `init()` (do NOT re-register):
  `GET /admin/login`, `POST /admin/login`.

```go
// internal/store (methods on *DB, hand-written database/sql — NOT sqlc)
func (db *DB) EnsureAdminUser(ctx) (UserID, error)          // idempotent, handle "admin", role "admin"
func (db *DB) ConsumeAdminToken(ctx, token []byte) error     // one-time via login_tokens; replay → ErrTokenReused (wrapped)
func (db *DB) CreateSession(ctx, userID UserID, role string) (string, error) // 32 rand bytes, base64url id, +24h
func (db *DB) SessionValid(ctx, id string) (UserID, string, bool, error)
func (db *DB) DeleteSession(ctx, id string) error            // idempotent
type UserID int64
var ErrTokenReused, ErrBadCredentials error                  // detect via errors.Is
var Now func() time.Time                                     // auth slice clock (see deviations)
```

`SessionValid` contract: missing/empty id → `(0, "", false, nil)` (the
everyday anonymous case); expired → `(0, "", false, err)` wrapping
`ErrBadCredentials`; DB failure → wrapped `%w`. Callers branch on `ok` only;
`AdminOnly` fails closed (redirect/401) on any `!ok` and sweeps expired rows
via `DeleteSession`.

New files (all inside owns): `internal/store/{user,session}.go`,
`internal/store/{user,session}_test.go`, `internal/web/{auth,session}.go`,
`internal/web/{auth,session}_test.go`. No other file touched; no new
dependencies; no "Phase N"/TODO/FIXME markers; token/cookie values never
logged.

## Spec deviations / reconciliations (for reviewer + planner)

1. **ADMIN_TOKEN encoding (the important one).** `config.Load()` stores the
   base64-**decoded** bytes in `Cfg.AdminToken`, but the operator — and the
   frozen A-201 oracle, `.env.test`, `scripts/*`, the Playwright webServer and
   `acceptance/e2e/util/admin.ts` — submit the **env value verbatim**
   (`dGVzdC1hZG1pbi10b2tlbi0zMi1ieXRl`). A literal compare against
   `Cfg.AdminToken` alone 403s the oracle's valid-token step. My real-binary
   smoke caught exactly this (403 instead of 302). Resolved inside my owns:
   `tokenMatches` constant-time-compares the submission against
   `Cfg.AdminToken` **and** its deterministic `base64.StdEncoding` — two
   encodings of one secret, so the accepted credential set does not widen and
   knowledge is equivalent. Consumption always uses the canonical config
   bytes, so every accepted encoding burns the **same** `login_tokens` row
   (pinned by "either accepted encoding burns the same one-time row").
   `internal/config` and the oracle are untouched. If the planner prefers
   ADMIN_TOKEN to stay raw in config, that is a one-line config change and
   `tokenMatches` degrades harmlessly (the encoded compare then accepts only
   the secret's own base64, i.e. the same value).
2. **Store clock exported as `Now`** (packet said package-level lowercase
   `now`). Store-local lowercase would be unreachable from package web, yet
   the packet requires the web-level case "expired session rejected (injected
   clock)". Exported `store.Now` serves both package's tests; production never
   mutates it; every swap restores via `t.Cleanup`.
3. **Cookie value = `base64url(id) + "." + hex(HMAC)`** implemented exactly as
   the packet words it (`base64url(id)`, i.e. the 43-char id is encoded
   again). The draft only checks the `gl_session=` prefix, so either reading
   is oracle-compatible; the test pins the implemented one.
4. **POST with blank token → 200 form** (uniform with the frozen GET blank
   case: empty = "nothing entered", not "wrong value"); POST missing/mismatched
   CSRF → 403. The draft freezes only the GET paths; POST rows are pinned by
   my tests for T-205's form work.
5. **Makefile variable**: `make e2e-task T=…` (AGENTS.md spelling) hits the
   target's usage error (exit 2) — the Makefile's variable is `TASK`. Use
   `make e2e-task TASK=T-203`.
