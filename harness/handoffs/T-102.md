## Frozen API as implemented (T-103 compiles against this)

```go
// internal/web/csrf.go — package web
const CSRFTokenName = "csrf_token" // cookie name AND hidden-input name (contract-frozen string)

var ErrCSRF = errors.New("csrf: token mismatch")

func IssueCSRFToken(w http.ResponseWriter, r *http.Request) string
func VerifyCSRF(r *http.Request, submitted string) error
```

Semantics T-103 should rely on:

- **Token format**: 32 `crypto/rand` bytes → `base64.RawURLEncoding` (43 chars,
  unpadded base64url; attribute-safe). "Well-formed" = strict raw-url decode to
  ≥ 32 bytes, total length ≤ 256 (DoS bound on hostile cookies/fields).
- **IssueCSRFToken**: if the request already carries a well-formed `csrf_token`
  cookie, its value is returned AS-IS and **no Set-Cookie is sent** (idempotent
  per session-less phase; pinned by test). Otherwise a fresh token is minted and
  set as a cookie: `Path=/`, `HttpOnly`, `SameSite=Lax`, `Secure` iff
  `serverFrom(r.Context()).Cfg.IsProd()`. Must be called from a handler inside
  the server chain (like every handler, it panics without the server in
  context). On the (unreachable) `crypto/rand` failure it answers 500 and
  returns `""`.
- **VerifyCSRF**: returns nil only if the request's `csrf_token` cookie exists
  and is well-formed AND the submission is non-empty/well-formed AND they are
  equal under `crypto/subtle.ConstantTimeCompare`. Every other outcome —
  missing cookie, empty, garbage, short, padded, over-long, mismatched — is
  `ErrCSRF`, uniformly (answer 403, don't distinguish causes).
- **Usage sketch for `/probe`**: render: `tok := IssueCSRFToken(w, r)` then
  embed `<input type="hidden" name="csrf_token" value="{{.CSRFToken}}">`;
  POST: parse the form into a typed struct at the boundary (rule 6), then
  `if err := VerifyCSRF(r, f.CSRFToken); err != nil { 403 }`.
