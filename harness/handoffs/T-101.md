## Review findings addressed in b8af66a

- **S1 (checksum asserted independently)** — new `independentSum` helper in
  `migrations_test.go` reads the embedded file bytes straight from
  `migrations.Files` (`fs.ReadFile`) and computes `sha256.Sum256` itself, NOT
  via `loadMigrations`. `checkRecordedChecksum` now asserts the DB-recorded
  value equals BOTH the independent digest and the runner-derived one, so a
  wrong-but-consistent hash implementation would fail.
- **S2 (recorded-without-file refusal untested)** — new
  `TestRecordedVersionWithoutEmbeddedFileRefusesOpen`: opens a real DB,
  inserts a `0002_ghost` row into `schema_migrations` via the raw driver,
  re-opens through the public `Open`, and asserts refusal naming `0002_ghost`
  with `errors.Is(err, ErrChecksumMismatch) == false`. Plus new
  `TestApplyMigrationsAppliesUnrecordedFilesInOrder` driving `applyMigrations`
  over an `fstest.MapFS` with two synthetic files: 0002 references 0001's
  table (order violation would fail), both versions recorded in order, each
  recorded checksum equals an independent sha256 of the synthetic bytes, and
  re-apply of the same set is a no-op.
- **S3 (guard error asserted by labels only)** — `TestMigrationChecksumGuard`
  now asserts the refusal message contains the ACTUAL 64-hex values: the
  tampered recorded sum (case preserved — uppercase case pins case-sensitive
  comparison) and the embedded file sum.
- **M1 (schema shape without constraints)** — `checkProbeColumns` now asserts
  via `PRAGMA table_info`: `id` INTEGER + `pk=1`; `n` INTEGER + `notnull=1` +
  `dflt_value="0"` + `pk=0`; and via `sqlite_master.sql`: the stored DDL
  contains `CHECK (id = 1)`, `NOT NULL`, `DEFAULT 0`. A migration dropping the
  CHECK/default now fails the "probe_table_columns_match_migration_ddl" test.
- **M2 + F2 (layout-pin test name/assertion)** — `scratch_tamper_test.go`
  renamed to `dbfile_layout_test.go`; the test is now
  `TestChecksumIsFirstAndOnlyHexTokenInDBFile` and asserts the recorded
  checksum is the ONLY `[0-9a-f]{64}` token in the closed main DB file
  (previously additional tokens were merely logged). Failure message points at
  the A-104 first-token oracle ambiguity and the sanctioned T-105 index-pin
  fallback. The uniqueness canary holds today (test green).
- **M3 (unusable-path test too weak)** — `TestOpenRefusesUnusablePath` is now
  a table (missing parent; `?` in path; `#` in path; `%` in path) asserting
  the refusal error names the path AND the offending substring.
- **F4 (dsn() does not escape the path)** — `Open` now calls `checkDSNPath`,
  which refuses `dbPath` containing `?`, `#` or `%` with a typed error
  (`errBadDSNPath`, `errors.Is`-able) rather than silently re-interpreting the
  filename via the driver's URL parsing. Open never escapes silently; T-103
  can still add config-level normalization, but the store is now safe on its
  own. Covered by the table above plus a `dsn_rejection_wraps_typed_error`
  subtest.
- **F5 (ErrNotFound via fmt.Errorf)** — now `errors.New`.
- **F1/B1 (deps)** — see section above; no code or dependency change was
  needed, the amended graph legitimizes the existing closure.
- **F3, F6** — no change needed (sanctioned canary; unsupported single-writer
  race), as the reviewers themselves concluded.

- **migrations/0001_init.sql** — exactly the packet's `probe` DDL + seed row

  `modernc.org/sqlite`; pragmas ride the DSN so every pooled connection gets
  them; `checkDSNPath` guard; sentinels `ErrNotFound`, `ErrChecksumMismatch`
  (the latter lives in migrations.go, wrapped by the refusal error).
- **internal/store/migrations.go** — runner-owned bookkeeping table
  `schema_migrations(version TEXT PRIMARY KEY, sha256 TEXT NOT NULL,
  applied_at TEXT NOT NULL)` (NOT in 0001). One transaction per file; version
  = filename sans extension; sha256 = lowercase hex of file bytes; applied_at
  = RFC3339 UTC. Refuses on recorded≠file (names file + both sums) and on
  recorded-without-file. Unrecorded files apply in `fs.Glob` lexical order.
  Reopen of an up-to-date DB writes nothing.
- **internal/store/queries/probe.sql + internal/store/gen/** — sqlc output
  committed; `make generate` and `make generate-check` are byte-stable.
- **Tests** — all table-driven, assertion-style names, no golden files, no
  skips/only/fixme; strengthened per the findings above.

### Frozen API as implemented (T-103 compiles against this)

```go
func Open(ctx context.Context, dbPath string) (*DB, error)
func (db *DB) Close() error
func (db *DB) ProbeCount(ctx context.Context) (int64, error) // wraps ErrNotFound
func (db *DB) ProbeInc(ctx context.Context) (int64, error)   // atomic UPDATE…RETURNING in tx
var ErrNotFound error            // store: not found
var ErrChecksumMismatch error    // wrapped by: store: migration 0001_init.sql checksum mismatch (recorded X, file Y): checksum mismatch
```

dbPath containing `?`/`#`/`%` is refused by `Open` (typed `errBadDSNPath`).
