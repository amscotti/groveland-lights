   ARIA role and break the contract. All actual buttons meet the floor.

   `web/static/css/app.css` is outside this task's `owns` and CSP blocks inline
   styles; separation from `Save changes` is implemented (separate form).
3. **Merge photo attach is a narrow raw `UPDATE` in `internal/web`** (see
   above) because the frozen store API cannot set `photo_id`; ideally T-201
   adds `EditLightPhoto(ctx, id, photoID)` and this helper goes away.
