## Round-3 review fixes (mapped to the review)

1. **No harness deletion / no guard bypass.** The previous attempt deleted the
   reviewer artifacts to satisfy the dirty-worktree check. They are present in
   the worktree now and were not modified; this handoff makes no cleanup claim.
2. **Bbox alert assertions are no longer vacuous.** `alertWithMessage` extracts
   the rendered `<article>` that actually carries
   `That position is outside Groveland town bounds` (so it cannot match the
   walk page's permanently hidden, empty `#walk-alert` placeholder), and
   `assertVisibleAlert` proves that element is `role="alert"` and not `hidden`.
   Both the full-page 422 and the HTMX 422 use it.
3. **`TestRenderAll` fails on a failed render.** The render error is checked per
   page and a blank document is rejected before the snapshot is written, so an
   incorrect fixture can no longer produce a zero-byte file that html-validate
   silently accepts.
4. **Dead CSRF branch removed.** `csrfInputValue` now returns `(value, ok)`;
   callers assert `ok`. The unreachable `== ""` branches are gone, and the walk
   page still compares the form value with the double-submit cookie.
5. **Pager assertions are scoped to the pager form.**
   `pagerFormOf`/`assertPagerPageInput` extract the `method="get"
   action="/admin/rows"` form carrying the `Older`/`Newer` button, then assert
   the hidden `page` input and matching `hx-get` are inside that form. A stray
   input elsewhere no longer passes.
6. **Anonymous edit/delete routes covered.** `TestAdminRoutesGuard` now posts
   `/admin/lights/1` and `/admin/lights/1/delete` without a session and asserts
   the 302 to `/admin/login`, in addition to the existing GET/create cases.
7. **Merge photo goes through the store.** `internal/store/queries/lights.sql`
   gained `UpdateLightPhoto`; `store.EditLightPhoto(ctx, id, photoID)` wraps it
   (live-row guard, `ErrNotFound`, foreign-key enforcement, `updated_at`
   stamp). `internal/web/admin_merge.go` is now a thin `attachPhoto` wrapper
   around that method; the second SQLite connection, raw `UPDATE` and duplicate
   DSN are gone. `TestEditLightPhoto` covers the success path (only `photo_id`
   moves; label/asset/position survive; `updated_at` re-stamps), missing and
   soft-deleted ids (`ErrNotFound`), and a canceled context (a wrapped driver
   error, not `ErrNotFound`).
