## What changed in this retry

1. **Merge-photo now goes through the store, atomically.**
   - New `internal/store/lights_photo.go` (planner-ratified owns extension):
     `EditLightPhoto(ctx, id, label, assetNo, photoID)`.
   - It runs `UPDATE label/asset` and `UPDATE photo_id` inside ONE transaction,
     so a failed photo write rolls the label/asset back; commit is the only
     durable point. Missing/soft-deleted ids wrap `store.ErrNotFound`, duplicate
     asset numbers wrap `store.ErrDuplicateAssetNo`, FK failures surface as DB
     errors. `internal/store/lights_photo_test.go` covers the round trip,
     missing/soft-deleted ids, duplicate-asset rollback and unknown-photo
     rollback.
   - `internal/web/admin_merge.go` no longer contains any `sql.DB`, DSN or SQL.
     `mergeDuplicate` calls `EditLightPhoto` (with photo) or `EditLight` (without)
     and maps a vanished duplicate to a plain create.
2. **The self-deleting Playwright harness is gone.** No spec/config/Go cleanup
   file lives under `web/templates/**`; no `tmp_cleanup.go`. The visual flow was
   run from the packet-sanctioned `scratch/` directory and `scratch/` was
   removed before commit (verified clean `git status`).
3. **Swallowed errors fixed.**
   - `classifyDuplicate` now returns its store error; a failed
     `LightByAssetNo`/`NearbyLights` answers 500 instead of creating the light
     with duplicate detection disabled. `TestAdminCreateDuplicateLookupFailure`
     drops the `lights` table while keeping sessions usable, and pins both the
     nearby and asset-number paths.
   - `mergeDuplicate` only falls back to create for `ErrNotFound`; other
     `GetLight` failures answer 500.
   - `installLoginPage` no longer silently keeps the legacy page: a template
     parse/render failure panics with the template name at init.
4. **CSRF order corrected.** Multipart parsing is now syntactic only; label /
   asset / kind / position / accuracy / dup_choice validation runs *after*
   `VerifyCSRF`. A malformed body with a missing token answers 403, not 422
   (`TestAdminCreateValidation/csrf_is_checked_before_field_validation`).
5. **Vacuous assertions removed.**
   - Validation cases assert the exact frozen message is inside a visible
     `role="alert"` element (`assertVisibleAlert`), not just anywhere in the
     page.
   - The unnumbered duplicate test extracts `#dup-panel` before asserting
     `Save anyway`, so the always-present hidden low-accuracy button cannot
     satisfy it.
   - The merge-photo test no longer blesses the replaced photo as a required
     200 response; it asserts the survivor references the new photo and does
     not reference the old URL.
6. **Dead code removed:** `listData.Page` and `badSubmission.Error`.
7. **Tap target:** the SVG pin keeps its 22 px visual circle but gains an
   invisible r=22 hit circle, so its box is ≥44 px on the mobile viewports.
