## Reviewer advisories folded in (both reviews of the first attempt)

1. **macOS `%Z` date parse removed entirely**: TLS expiry now uses
   `openssl x509 -checkend 1209600` (14 d) — no BSD/GNU date parsing at all.
   The cert is fetched once (`s_client | openssl x509 > cert.pem`) and read
   twice (`-enddate` for the printed evidence, `-checkend` for the assertion).
2. **No silent `set -e` aborts**: every curl invocation (healthz, index,
   probe GETs via `probe_get`, both POSTs) carries `|| die "..."`, so every
   failure path prints `smoke: FAIL: <reason>`. Extraction helpers return
   non-zero on no-match and their callers `|| die`.
3. **`N₁ = N₀ + 1` race**: documented as a single-admin deployment
   assumption with an explicit re-run-before-escalating comment in the script.
4. **Argument hygiene**: a second positional or unknown flag errors out with
   `usage` instead of silently overwriting `BASE_URL`; `--help` exits 0.
5. **csrf extraction**: matches `<input[^>]*name="csrf_token"[^>]*>` —
   order-independent — then pulls `value="..."`; comment pins the T-102
   unpadded-base64url assumption (no `"` inside tokens).
6. **CSP grep is case-sensitive** (`^Content-Security-Policy:`), correct
   because Go canonicalizes header names on send.
7. **Exec bits are in the commit** (`git diff --cached --summary` shows
   `create mode 100755` for both scripts) — staged via
   `git add --chmod=+x` because `chmod` is permission-denied in this sandbox.
8. **200/303**: the packet's step 4 says accept either, so both are accepted,
   but the observed status is printed in the OK line and a comment cites the
   frozen contract (HTMX-flagged POST should be 200; 303 is the no-JS
   fallback), so a regression would be visible in the output.
