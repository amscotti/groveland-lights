## Proposed deliverables (apply verbatim once unblocked)

### `scripts/docker-entrypoint.sh` (new, mode 0755)

```sh
#!/bin/sh
# Container entrypoint (plan §5.3): fix /data ownership, drop to appuser, exec.
#
# Fly volumes mount /data as root:root; the app runs as uid 10001 (appuser)
# and cannot write there unaided. As root we repair ownership best-effort,
# then drop privileges and exec the server command. Local runs without a
# volume mount skip the chown harmlessly — point DB_PATH/PHOTO_DIR at a
# writable location in that case.
set -eu

DATA_DIR="${DATA_DIR:-/data}"

if [ -d "$DATA_DIR" ]; then
  chown -R 10001:10001 "$DATA_DIR" || true
fi

exec su-exec appuser "$@"
```

Notes: runs as root only for the chown; `|| true` covers local runs with no
mount; `su-exec` is added to the runtime image below (tiny); `exec` replaces
the shell so the server is PID 1 and receives signals for graceful shutdown.

### `Dockerfile` (runtime stage only; build stage untouched)

```dockerfile
# syntax=docker/dockerfile:1

FROM golang:1.27.4-alpine AS build
WORKDIR /src
COPY go.mod go.sum ./
RUN go mod download
COPY . .
RUN CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o /out/server ./cmd/server

FROM alpine:3.22
RUN apk add --no-cache ca-certificates tzdata su-exec \
 && adduser -D -H -u 10001 appuser
COPY --from=build /out/server /app/server
COPY scripts/docker-entrypoint.sh /docker-entrypoint.sh
RUN chmod 0755 /docker-entrypoint.sh
# Entrypoint starts as root to repair /data ownership, then drops to appuser.
USER root
EXPOSE 8080
ENV PORT=8080
ENTRYPOINT ["/docker-entrypoint.sh"]
CMD ["/app/server"]
```

Delta vs current file: `su-exec` added to the apk line, the two COPY/RUN lines
for the entrypoint, `USER appuser` → `USER root` (required: the entrypoint
must be root to chown; privileges are dropped via su-exec), ENTRYPOINT/CMD
split. Alpine stays pinned at 3.22; size stays well under 40 MB (su-exec ≈
30 KB); build stage byte-identical.

### `scripts/smoke.sh` (new, mode 0755)

Written against the frozen probe contract in `harness/tasks/T-103.md`
(fragment: `<span id="probe-count">N</span>` + hidden input named
`csrf_token`; POST valid → 200 HTMX / 303 plain; bogus token → 403, count
unchanged; `/healthz` → 200 `ok`; CSP header set by
`internal/web/web.go withSecurityHeaders` for every response). No associative
arrays, no `${var,,}`, no mapfile — macOS bash 3.2 safe. Every check line is
prefixed `smoke:`; the header carries UTC date + git sha so two runs around a
deploy prove persistence.

```bash
#!/usr/bin/env bash
# Deployed smoke run (plan §11): prints evidence that the /probe counter
# survived the deploy.
#
#   scripts/smoke.sh <BASE_URL> [--smoke-suite]
#
# <BASE_URL>      e.g. https://groveland-lights.fly.dev
# --smoke-suite   also run `make smoke BASE_URL=<url>` (Playwright @smoke
#                 specs; skipped with a note if node_modules is absent)
#
# Exits non-zero on the first failed check.
set -euo pipefail

REPO="$(cd "$(dirname "$0")/.." && pwd)"
SMOKE_SUITE=0
BASE_URL=""

usage() { echo "usage: scripts/smoke.sh <BASE_URL> [--smoke-suite]" >&2; }

for arg in "$@"; do
  case "$arg" in
    --smoke-suite) SMOKE_SUITE=1 ;;
    -h|--help) usage; exit 0 ;;
    *) BASE_URL="$arg" ;;
  esac
done

[ -n "$BASE_URL" ] || { usage; exit 2; }
BASE_URL="${BASE_URL%/}"

die() { echo "smoke: FAIL: $*" >&2; exit 1; }

REV="$(git rev-parse --short HEAD 2>/dev/null || echo no-git)"
TMP="$(mktemp -d)"
trap 'rm -rf "$TMP"' EXIT
JAR="$TMP/cookies.jar"

http_get() { # $1 url; sets CODE and BODY; sends/receives the CSRF cookie jar
  local url="$1"
  CODE="$(curl -sS --connect-timeout 5 -m 15 -c "$JAR" -b "$JAR" \
    -o "$TMP/body" -w '%{http_code}' "$url")"
  BODY="$(cat "$TMP/body")"
}

extract_csrf() { # $1 html -> stdout: csrf_token hidden-field value
  local html="$1" token=""
  html="$(printf '%s' "$html" | tr '\n\r' '  ')"
  token="$(printf '%s' "$html" \
    | sed -n 's/.*name="csrf_token"[^>]*value="\([^"]*\)".*/\1/p' | head -n 1)"
  if [ -z "$token" ]; then
    token="$(printf '%s' "$html" \
      | sed -n 's/.*value="\([^"]*\)"[^>]*name="csrf_token".*/\1/p' | head -n 1)"
  fi
  printf '%s' "$token"
}

extract_count() { # $1 html -> stdout: integer in <span id="probe-count">
  local html="$1" n
  html="$(printf '%s' "$html" | tr '\n\r' '  ')"
  n="$(printf '%s' "$html" \
    | sed -n 's/.*id="probe-count">\([0-9][0-9]*\)<\/span>.*/\1/p' | head -n 1)"
  printf '%s' "$n"
}

cert_enddate() { # $1 host -> stdout: "Jun  1 12:00:00 2027 GMT" style value
  local host="$1" out
  out="$(echo | openssl s_client -servername "$host" -connect "$host:443" 2>/dev/null \
    | openssl x509 -noout -enddate 2>/dev/null)" || return 1
  out="${out#notAfter=}"
  [ -n "$out" ] || return 1
  printf '%s\n' "$out"
}

epoch_of() { # $1 date string -> stdout: epoch seconds (GNU then BSD date)
  local s="$1" e
  e="$(date -d "$s" +%s 2>/dev/null)" && { printf '%s\n' "$e"; return 0; }
  s="$(printf '%s' "$s" | tr -s ' ')"
  e="$(date -ju -f '%b %d %H:%M:%S %Y %Z' "$s" +%s 2>/dev/null)" \
    && { printf '%s\n' "$e"; return 0; }
  return 1
}

echo "smoke: run $(date -u +%Y-%m-%dT%H:%M:%SZ) rev=$REV target=$BASE_URL"

# 1. healthz
http_get "$BASE_URL/healthz"
[ "$CODE" = "200" ] || die "healthz: want 200, got $CODE"
[ "$BODY" = "ok" ] || die "healthz: want body 'ok', got '$BODY'"
echo "smoke: healthz OK"

# 2. TLS: certificate must be >= 14 days from expiry (https targets only)
case "$BASE_URL" in
  https://*)
    HOST="$(printf '%s' "$BASE_URL" | sed -e 's|^https://||' -e 's|/.*$||')"
    END_DATE="$(cert_enddate "$HOST")" || die "tls: cannot read certificate for $HOST"
    END_EPOCH="$(epoch_of "$END_DATE")" || die "tls: cannot parse notAfter '$END_DATE'"
    NOW="$(date -u +%s)"
    DAYS_LEFT=$(( (END_EPOCH - NOW) / 86400 ))
    [ "$END_EPOCH" -ge $(( NOW + 14 * 86400 )) ] \
      || die "tls: certificate expires in $DAYS_LEFT days (< 14)"
    echo "smoke: tls OK (certificate expires in $DAYS_LEFT days)"
    ;;
  *)
    echo "smoke: tls SKIPPED (target is not https)"
    ;;
esac

# 3. GET / -> 200 and CSP header present
CODE="$(curl -sS --connect-timeout 5 -m 15 -o /dev/null -D "$TMP/headers" \
  -w '%{http_code}' "$BASE_URL/")" || die "GET /: curl failed"
[ "$CODE" = "200" ] || die "GET /: want 200, got $CODE"
grep -qi '^content-security-policy:' "$TMP/headers" \
  || die "GET /: Content-Security-Policy header missing"
echo "smoke: csp OK"

# 4. Probe persistence evidence
http_get "$BASE_URL/probe"
[ "$CODE" = "200" ] || die "GET /probe: want 200, got $CODE"
TOKEN="$(extract_csrf "$BODY")"
[ -n "$TOKEN" ] || die "GET /probe: no csrf_token hidden field in fragment"
N0="$(extract_count "$BODY")"
case "$N0" in ''|*[!0-9]*) die "GET /probe: no readable probe count" ;; esac
echo "smoke: probe GET OK (count=$N0)"

CODE="$(curl -sS --connect-timeout 5 -m 15 -b "$JAR" -c "$JAR" -o "$TMP/body" \
  -w '%{http_code}' -H 'HX-Request: true' \
  --data-urlencode "csrf_token=$TOKEN" "$BASE_URL/probe")" \
  || die "POST /probe: curl failed"
[ "$CODE" = "200" ] || [ "$CODE" = "303" ] \
  || die "POST /probe: want 200 (HTMX) or 303 (plain), got $CODE"

http_get "$BASE_URL/probe"
N1="$(extract_count "$BODY")"
case "$N1" in ''|*[!0-9]*) die "POST /probe: unreadable count after increment" ;; esac
echo "smoke: probe count $N0 -> $N1"
[ "$N1" -eq $(( N0 + 1 )) ] \
  || die "probe persistence: want count $(( N0 + 1 )), got $N1"
echo "smoke: probe increment OK"

CODE="$(curl -sS --connect-timeout 5 -m 15 -b "$JAR" -c "$JAR" -o /dev/null \
  -w '%{http_code}' -H 'HX-Request: true' \
  --data-urlencode 'csrf_token=bogus-token' "$BASE_URL/probe")" \
  || die "POST /probe (bad token): curl failed"
[ "$CODE" = "403" ] || die "POST /probe (bad token): want 403, got $CODE"
http_get "$BASE_URL/probe"
N2="$(extract_count "$BODY")"
[ "$N2" = "$N1" ] || die "POST /probe (bad token): count changed $N1 -> $N2"
echo "smoke: probe csrf-reject OK (count unchanged at $N1)"

# 5. Optional Playwright @smoke suite
if [ "$SMOKE_SUITE" -eq 1 ]; then
  if [ -d "$REPO/node_modules" ]; then
    ( cd "$REPO" && make smoke BASE_URL="$BASE_URL" ) \
      || die "suite: make smoke failed"
    echo "smoke: suite OK"
  else
    echo "smoke: suite SKIPPED (node_modules absent)"
  fi
fi

echo "smoke: all checks passed $(date -u +%Y-%m-%dT%H:%M:%SZ) rev=$REV"
```

## Machine-unverified paths (for the human / CI — nothing here ran them)

Everything in this task is machine-unverified locally, by design (no docker/
flyctl/curl permission) and now additionally because the files exist only in
this handoff. Apply the five files, then:

1. Static hygiene: `bash -n scripts/smoke.sh scripts/docker-entrypoint.sh`
   and `shellcheck scripts/smoke.sh scripts/docker-entrypoint.sh`
   (shellcheck 0.11.0 is pinned in mise/`make doctor`).
2. Image build + size (CI runs this via `make ci` → `make docker-build`):
   `docker build -t groveland-lights:dev .`
3. Entrypoint with a volume (the H4-adjacent path):
   `docker run --rm -p 8080:8080 -v gl-data:/data -e APP_ENV=prod \
    -e SESSION_KEY=… -e IP_HASH_KEY=… -e ADMIN_TOKEN=… groveland-lights:dev`
   then confirm `/data/lights.db` is created and `appuser` owns it.
4. Fly: `flyctl deploy --ha=false` (fly.toml validates as part of deploy;
   `flyctl config validate` alone is optional), then
   `scripts/smoke.sh https://groveland-lights.fly.dev` before and after a
   redeploy — the second run's `smoke: probe count N₀ -> N₁` line with N₀
   carried over from the first run is the persistence evidence M1 wants.
5. Full deployed suite: `scripts/smoke.sh https://groveland-lights.fly.dev
   --smoke-suite` (runs `make smoke` = Playwright @smoke specs).
