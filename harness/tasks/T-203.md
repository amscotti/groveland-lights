## Deliverable 1 — store slice (hand-written database/sql, NO sqlc)

`internal/store/session*.go` + `internal/store/user*.go`, methods on `*DB`
(same package; you may read store.go's private fields but NOT edit any file
outside your owns globs):

- `EnsureAdminUser(ctx) (UserID, error)` — idempotent INSERT of handle `admin`,
  role `admin` (INSERT ... ON CONFLICT(handle) DO NOTHING then SELECT).
- `ConsumeAdminToken(ctx, token []byte) error` — one-time semantics via
  `login_tokens`: token_hash = hex(sha256(token)); first call INSERTs the row
  (email `admin`, expires_at now+24h, used_at now) and succeeds; a second call
  finds used_at non-NULL → `ErrTokenReused`; a DB error wraps with %w.
- `CreateSession(ctx, userID, role) (id string, err)` — 32 random bytes
  (crypto/rand) base64url, row with created_at/expires_at (now+24h, RFC3339).
- `SessionValid(ctx, id) (userID, role, ok, err)` — exists, matching, unexpired.
- `DeleteSession(ctx, id)`.
- Sentinel errors: `ErrTokenReused`, `ErrBadCredentials`. Unit tests with a real
  temp-file DB (migrations applied): consume-once, expiry boundary via an
  injectable clock (package-level `now func() time.Time` var), session round-trip.

## Deliverable 2 — web handlers `internal/web/auth*.go` + `internal/web/session*.go`

Register via `init()` (never edit web.go):

- `GET /admin/login` (no/blank token) → 200 full page rendering the existing
  template pipeline is T-205's; for now render a MINIMAL inline page yourself:
  heading `Admin login`, form (method GET or POST to `/admin/login`) with label
  `Token`, input name `token`, button `Sign in`. T-205 will replace the markup
  with a proper template WITHOUT changing these strings.
- `GET /admin/login?token=X` and `POST /admin/login` (form field `token`,
  CSRF-verified like other POSTs):
  - constant-time compare against `s.Cfg.AdminToken`; mismatch → 403.
  - `ConsumeAdminToken` → `ErrTokenReused` → 403 (replay).
  - success → `EnsureAdminUser` + `CreateSession`, set cookie `gl_session` =
    base64url(id) + "." + hex(HMAC-SHA256(SessionKey, id)), `Path=/`,
    `HttpOnly`, `SameSite=Lax`, `Secure` when `s.Cfg.IsProd()`, MaxAge 24h;
    redirect 302 to `/admin`.
- `AdminOnly(next http.HandlerFunc) http.HandlerFunc` (exported; T-205 wraps
  every admin route with it): valid session+role admin → next; otherwise full
  page → 302 `/admin/login`; `HX-Request` set → 401 with header
  `HX-Redirect: /admin/login` and empty body.
- Log via `s.Log`; never log the token. Parse inputs at the boundary into a
  typed struct (`loginForm`); no `r.FormValue` after parsing.
