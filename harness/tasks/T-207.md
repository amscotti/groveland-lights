## Why this task exists

T-200 wrote every M2 spec as an INERT DRAFT (`acceptance/drafts/*.txt` and
holdout `drafts/`) because the merge gate runs full `make check` per task. All
features are now merged. You activate the drafts — by rename, not rewrite — so
the oracle-first property stays auditable in git history. You know the drill
from T-105; its review (harness/reviews/T-105-reviewer.md) is required reading.

## Rules of activation (learned the hard way in M1)

1. `git mv` each draft to its runnable location
   (`acceptance/drafts/admin-walk.spec.ts.txt` →
   `acceptance/e2e/admin-walk.spec.ts`, `acceptance/drafts/admin_auth_go_test.go.txt`
   → `acceptance/go/admin_auth_test.go`,
   `acceptance/drafts/admin_lights_go_test.go.txt` →
   `acceptance/go/admin_lights_test.go`; holdout drafts → their `go/`/`e2e/`).
2. Run everything. Expected: all green, all four Playwright projects.
3. **If a test fails, decide which side is wrong BEFORE touching anything:**
   - The FEATURE violates the frozen contract (see T-200's packet and the
     building tasks' packets) → do NOT edit the test. Write
     `BLOCKED: A-### unmet — <precise gap>` in your handoff; the planner cuts
     a fix task. This is the correct terminal state, not a failure of yours.
   - The draft has a mechanical defect that cannot change what it asserts
     (unsatisfiable extractor against ANY contract-compliant markup, a selector
     that must be scoped, a flaky wait needing `expect.poll`) → you MAY make
     the minimal edit and MUST list every such edit with a one-line
     justification. Anything that weakens an assertion (looser match, removed
     check, moved observation point, added skip) is forbidden and both
     reviewers will look for exactly that.
4. No `t.Skip`/`test.skip`/`test.only`/`.fixme` anywhere.
5. Preserve the contract table: move `acceptance/drafts/README.md`'s frozen
   contract table + visual notes into a new permanent `acceptance/README.md`
   before deleting the (then-empty) drafts dir. The validator and
   visual-reviewer use those visual notes for M2.
