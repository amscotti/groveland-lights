## Deliverables

### internal/web/csrf.go — frozen API (T-103 compiles against this)

Double-submit cookie pattern, stdlib only:

- `func IssueCSRFToken(w http.ResponseWriter, r *http.Request) string`
  — generate ≥32 bytes of `crypto/rand`, return base64url; ALSO set cookie
  `csrf_token` (Path=/, HttpOnly, SameSite=Lax, Secure when prod). If the
  request already carries a well-formed cookie, reuse its value (idempotent
  per session-less phase).
- `var ErrCSRF = errors.New("csrf: token mismatch")`
- `func VerifyCSRF(r *http.Request, submitted string) error`
  — submitted must be non-empty, base64url-shaped, and equal to the request's
  `csrf_token` cookie compared in constant time (`crypto/subtle`). Missing
  cookie, empty/garbage/mismatched submission → `ErrCSRF`.

Tests (`csrf_test.go`, table-driven, case names as assertions): "missing cookie
rejected", "empty submission rejected", "tampered value rejected", "valid
round-trip accepted", "issue is idempotent per cookie", "cookie flags in prod
vs test" (use `httptest` + the `testConfig`-style config from `web_test.go` —
construct `config.Config` inline; do not edit `web_test.go`).

### internal/web/middleware_logging_test.go (and more guard tests as useful)
