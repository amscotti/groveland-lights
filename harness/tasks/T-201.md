## Deliverable 2 — sqlc queries + regenerated code

Add `internal/store/queries/lights.sql` and `photos.sql`; regenerate with
`make generate` and COMMIT the output (the gate's `generate-check` diffs it).
Queries needed (names free, capabilities fixed):

- CreateLight (all columns incl. created_at/updated_at RFC3339 strings, NULL
  photo_id/asset_no/created_by allowed); GetLight(id); GetLightByAssetNo (must
  exclude deleted); ListRecentLights(limit, offset) newest-first, excluding
  deleted; UpdateLight(label, asset_no, updated_at); SoftDeleteLight(id,
  deleted_at=now); NearbyLights(minLat,maxLat,minLon,maxLon) excluding deleted
  (a bounding-box prefilter; exact distance is computed in Go by internal/geo,
  another task — just return the rows).
- CreatePhoto(path,width,height,bytes,sha256); GetPhoto(id); ListPhotos(limit).

## Deliverable 3 — typed wrappers `internal/store/lights.go`, `internal/store/photos.go`

Methods on `*DB` (the existing type in store.go — you may NOT edit store.go):
`CreateLight(ctx, NewLight) (Light, error)`, `GetLight(ctx, LightID)`,
`LightByAssetNo`, `RecentLights(ctx, limit, offset)`, `EditLight`,
`SoftDeleteLight`, `NearbyLights(ctx, lat, lon, radiusM)` (computes the bbox from
radius, ≤ a degree-level safety margin), `CreatePhoto`, `PhotoByID`. Domain
types in the same files: `type LightID int64`, `type PhotoID int64`,
`type Kind string` (`park|building|street`) with `ParseKind`, `NewLight` struct
(typed fields; `AssetNo *string`/`PhotoID *PhotoID` for NULLs). Map
`sql.ErrNoRows` → `ErrNotFound`. `EditLight`/`SoftDeleteLight` on a missing or
deleted id → `ErrNotFound`. Sentinels: `ErrDuplicateAssetNo` when CreateLight
hits the unique index.

## Deliverable 4 — tests (real temp-file SQLite, migrations applied, never mocks)

Put them ONLY in files matching your owns globs (`internal/store/lights_test.go`,
`photos_test.go`, extend `migrations_test.go`):

- `TestSchemaMatchesExpected` (in migrations_test.go): open a fresh DB, read
  `SELECT sql, type FROM sqlite_master WHERE name NOT LIKE 'sqlite_%'`, strip

  `testdata/schema.expected.sql` (same normalization).
- `TestMigrationsUpgradeWithData`: apply 0001 only (temp copy of the embedded
  FS filtered to 0001), insert a probe row, then full-open → probe row survives,
  `PRAGMA foreign_key_check` empty, `integrity_check` = ok.

  `LightByAssetNo` + `NearbyLights` at Haversine-derived offsets for 7.9 m / 8.1 m

- Soft delete (A-208): deleted light excluded from RecentLights/NearbyLights/
  GetLight (GetLight → ErrNotFound), asset_no freed for reuse (partial unique
  index semantics).
- Photos round-trip: create → fetch; path uniqueness enforced.
