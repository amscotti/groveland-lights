## Deliverable — package `internal/geo` with this frozen API

```go
package geo

// Duplicate thresholds (metres). NumberedRadiusM sizes the near-candidate
// query; same-asset_no duplicates are caught by the unique index + lookup, so
// the 25 m figure only bounds the candidate window. UnnumberedRadiusM is the
// hard "possible duplicate" distance for unnumbered fixtures.
const (
    NumberedRadiusM   = 25.0
    UnnumberedRadiusM = 8.0
)

type Point struct{ Lat, Lon float64 }

// DistanceM is the great-circle distance between two points in metres
// (Haversine, mean Earth radius 6371008.8 m — freeze this constant).
func DistanceM(a, b Point) float64

type Candidate struct {
    LightID int64
    AssetNo string // "" when the existing fixture is unnumbered
    Point   Point
}

// DupDecision reports why a submission is a possible duplicate.
type DupDecision struct {
    Numbered   bool   // true: same non-empty asset_no as an existing light
    ExistingID int64
    DistanceM  float64
}

// ClassifyDuplicate returns (decision, true) when newAssetNo matches a
// candidate's non-empty asset_no (Numbered), or when BOTH the new fixture is
// unnumbered (newAssetNo == "") AND a candidate with empty AssetNo stands
// within UnnumberedRadiusM. Otherwise (zero, false).
func ClassifyDuplicate(newAssetNo string, newPt Point, existing []Candidate) (DupDecision, bool)
```

## Tests (internal/geo/*_test.go, table + property)

- Distance table: known pairs with hand-computed Haversine values (e.g.
  ~111.19 km per degree of latitude at the equator side, Groveland-local pairs
  around 42.76,-71.03); tolerance 0.5 m. Zero distance; antipodes.
- Property loops (seeded math/rand, no new deps): DistanceM(a,b)==DistanceM(b,a)
  (symmetry); DistanceM(a,c) <= DistanceM(a,b)+DistanceM(b,c) (triangle
  inequality); distance >= 0 always.
- Classify table, names like assertions: "same asset_no anywhere is numbered
  duplicate" (distance 2 km), "unnumbered within 8 m is duplicate" (7.9 m yes,
  8.1 m no), "numbered new fixture near unnumbered existing is NOT unnumbered
  duplicate", "empty candidate list never duplicates", "first match wins with
  nearest preferred" (two candidates within 8 m → nearest reported).
